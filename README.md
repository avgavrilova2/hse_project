## Как запустить

Нужны [Git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/).
Python отдельно ставить не нужно — его поставит uv.

```bash
git clone git@github.com:ВАШ_ЛОГИН/prime-monitor.git
cd prime-monitor
uv sync
```

Доступ к учебной базе выдаёт бот курса по команде `/db`. Полученную строку
подключения кладём в `.env`:

```bash
cp .env.example .env
# и вписать в .env строку из бота
```

Проверка, что всё встало:

```bash
uv run python -c "from prime.config import get_engine; print(get_engine().connect().execute(__import__('sqlalchemy').text('select current_user')).scalar())"
```

Запуск JupyterLab:

```bash
uv run jupyter lab
```

## Что здесь считается
1. Неуспешные платежи. Доля неуспешных платежей:3.3%. Сумма неуспешных платежей:8965.0. Считается на данных таблицы Payment. Посчитано: failed_share = failed_count/len(rows)*100.
2. И успешные, и неуспешные платежи у 4 участников.Считается на данных таблицы Payment.В среднем приходится операций на одного участника:1.065. Подсчет:avg_rows_per_actor = len(rows) /len({row['actor_id'] for row in rows})
3. Главный день недели.По сумме сделок лидерами являются такие дни недели как четверг, суббота и понедельник, что также справедливо и по средней сумме (эти дни в том числе лидеры). Считается на данных таблицы Payment.
4. Самый активный участник. Считается на данных таблицы Payment. Первое место делят два участника, так как они оба купили 3 раза подписку/ 3 раза провели операции. Был выбран лидер c032a9e3-b9b0-4967-a5e7-7ab09c9d60e4, так как его actor_id меньше при сравнении как текст, то есть в соответсвии с правилом был выбран участник.
5. Три пиковые дня.Считается на данных таблицы Payment. Пик активности наблюдается на конец рабочей недели, когда у людей приближаются выходные, и возможно, спадает нагрузка по работе, и у них есть время для пользованием сервера, а в выходные люди отдыхают.
6. Равномерно ли набирается сумма внутри окна.Считается на данных таблицы Payment.17 августа 2025 г (порядковый номер равен 48) накопленное превысило половины суммы. Первая половину суммы достигла 4,66%. Вышло ранее, чем середина и др
