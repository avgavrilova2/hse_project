## Что здесь

Проект загружает из базы ПРАЙМ данные о клиентах, подписках, платежах и участниках подписок. Формирует клиентскую витрину: рассчитывает количество подписок, выручку от успешных платежей и признаки владения и участия в подписках. В Jupyter-ноутбуке показывает итоговую таблицу и результаты проверок уникальности клиентов, корректности соединений и сохранения общей выручки.

## Как запустить

Нужны [Git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/).
Python отдельно ставить не нужно — его поставит uv.

```bash
git clone git@github.com:ВАШ_ЛОГИН/prime-monitor.git
cd prime-monitor
uv sync
```

Доступ к учебной базе выдаёт бот курса по команде `/db`. Полученную строку
подключения кладём в `.env`:

```bash
cp .env.example .env
# и вписать в .env строку из бота
```

Проверка, что всё встало:

```bash
uv run python -c "from prime.config import get_engine; print(get_engine().connect().execute(__import__('sqlalchemy').text('select current_user')).scalar())"
```

Запуск JupyterLab:

```bash
uv run jupyter lab
```

## Что здесь считается

Количество подписок, принадлежащих каждому клиенту.

Выручка от успешных платежей по подпискам клиента.

Признак того, является ли клиент владельцем подписки.

Признак участия клиента в подписках.

Количество уникальных клиентов, являющихся владельцами или участниками, без повторного счёта людей, совмещающих обе роли
